# CV Web Responsive

Currículum desarrollado desde cero con HTML5 y CSS3.

## Características

- HTML semántico
- CSS organizado mediante componentes
- Sistema de variables CSS
- Flexbox y CSS Grid
- Timeline con pseudoelementos
- SVG personalizados
- Diseño preparado para impresión
- Responsive (en desarrollo)

## Tecnologías

- HTML5
- CSS3
- Flexbox
- CSS Grid
